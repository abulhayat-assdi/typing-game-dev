# R2 Architecture (M3)

Cloudflare R2 is the sole media store. Secrets never reach the browser:
all access flows through `apps/web/lib/server/r2.ts` (asserted by
`lib/server-boundary.test.ts`).

## Key conventions (`@tap/r2`, pure — no SDK, no I/O)

```
avatars/{userId}/{original|thumb}.{img}      PRIVATE (signed URLs only)
badges/{badgeSlug}/icon.{img}                public
worlds/{worldSlug}/{background|map|intro}    public
games/{gameSlug}/{preview|art}               public
sound/{pack}/{file} · audio/{pack}/{file}    public
ui/{surface}/{asset}                         public
competition/{competitionId}/{asset}          public
cosmetics/{cosmeticId}/asset                 public
promo/{campaign}/{asset}                     public
```

Builders (`avatarKey`, `worldKey`, `gameKey`, …) + `parseR2Key()` reject:
traversal (`..`, empty/doubled segments), backslashes, control bytes,
whitespace, absolute URLs, unknown prefixes, bad segment charset,
disallowed extensions (images vs audio per prefix), over-length keys.

`visibilityOf()` / `isSignable()` / `publicUrlFor()` separate the CDN path
(public, cache-friendly) from the signing path (private only).

## Signed-URL route

`GET /api/r2/signed-url?key=…&expiresIn=…` — default-deny:
503 `R2_NOT_CONFIGURED` (placeholders fail closed) → 401 without session →
400 for invalid/non-signable keys → 200 `{ url, key, expiresIn }`
(TTL clamped 60–3600s, default `R2_SIGNED_URL_TTL_SECONDS`). Signer failures
return 500 `SIGN_FAILED` without leaking internals. `presignPutUrl()` exists
as a tested server function; its upload route lands in a later milestone.

## Environment

Placeholders only in `.env.example`. Server: `R2_ACCOUNT_ID`,
`R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_PUBLIC_BUCKET`,
`R2_PRIVATE_BUCKET`, `R2_SIGNED_URL_TTL_SECONDS`. Browser-safe:
`NEXT_PUBLIC_R2_PUBLIC_BASE_URL`. Endpoint derives as
`https://<account>.r2.cloudflarestorage.com` (S3-compatible, `region: auto`).
Production secrets via `wrangler secret put`, never committed.
